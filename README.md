# GeTaTaPi

Мобильное приложение-игра, которое даёт повод выйти на улицу: ИИ выдаёт задание найти объект в реальном мире, пользователь фотографирует его, а нейросеть проверяет, подходит ли фото под задание.

---

## О проекте

Людям не хватает простого и игрового повода выходить на улицу и двигаться. Обычные шагомеры и фитнес-приложения мотивируют цифрами, но не дают «квеста».

GeTaTaPi превращает прогулку в игру: выбранная тема и сложность → задание от ИИ → фото найденного объекта → мгновенная проверка нейросетью → результат. Стрики и статистика помогают сформировать привычку.

Понятная причина выйти из дома и ощущение прогресса без сложных настроек и обучающих туториалов - все тут.

---

## Как это работает

1. Пользователь выбирает тему и уровень сложности.
2. Приложение запрашивает у Gemini задание на поиск объекта в реальном мире.
3. Пользователь фотографирует объект или выбирает фото из галереи.
4. Фото проходит проверку на адекватность и проверку соответствия заданию.
5. Результат: короткая вибрация — подошло, две «гудящие» — не подошло. Показывается пояснение от ИИ.
6. Фото можно сохранить в галерею устройства, опционально — с геометкой.
7. Стрики, статистика по темам и сложностям, «лучшие фото по мнению ИИ».

## Стек

| Слой | Технологии |
|---|---|
| **Платформа** | Android, Kotlin, minSdk 26 |
| **UI** | Jetpack Compose, MVVM (StateFlow) |
| **Архитектура** | Clean Architecture (UI → Domain → Data) |
| **Камера / галерея** | CameraX, `ActivityResultContracts.PickVisualMedia` |
| **Сеть** | Retrofit + OkHttp |
| **DI** | Hilt |
| **Локальное хранилище** | Room + DataStore |
| **Backend** | Supabase (Auth, Postgres, Storage, Edge Functions) |
| **AI (проверка)** | Gemini API (Flash-Lite для MVP) |
| **AI (пре-фильтр)** | VKCloud Vision |

Ключ Gemini API не хранится в клиенте: запросы идут через прокси — Supabase Edge Function.
